# GitScope — GitHub Profile Viewer

A clean, minimal web app to explore any GitHub user's profile, repositories, and language stats.

🔗 **Live Demo:** https://abidm12.github.io/gitscope-profile-viewer

---

## Features

- Search any GitHub username
- View profile info — avatar, bio, location, website
- See follower, following, and repo counts
- Browse top repositories with stars and forks
- Language stats across all repos
- Responsive design — works on mobile and desktop

---

## Tech Stack

| Layer | Technology |
|---|---|
| Markup | HTML5 |
| Styling | CSS3 (Variables, Flexbox, Grid) |
| Logic | Vanilla JavaScript (ES6+) |
| Data | GitHub REST API v3 |
| Fonts | JetBrains Mono, Sora (Google Fonts) |

---

## Run Locally

```bash
git clone https://github.com/Abidm12/gitscope-profile-viewer.git
cd gitscope-profile-viewer
```

Open `index.html` in your browser. No install or build step needed.

---

## Key Concepts Used

- `async/await` with `Promise.all()` for parallel API calls
- Dynamic DOM rendering
- CSS custom properties for theming
- Responsive layout with CSS Grid auto-fill
